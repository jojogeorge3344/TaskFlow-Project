# SCREEN 11: Task Update and Comments Screen

> Source: BRD for Task management.docx · TaskFlow – Intelligent Task Allocation & Tracking System · v1.0 · §2.11

**Screen Name:** Task Discussion and Updates
**Access:** Authorized task participants

## Purpose

Allow employees and managers to communicate about a task.

## Screen Elements

- Task information summary.
- Comment input box.
- Submit comment button.
- Comment history.
- Author name.
- Comment timestamp.

## Functional Requirements

1. Allow authorized users to add comments.
2. Display comments in chronological order.
3. Record the author and timestamp of each comment.
4. Validate that comments are not empty.
5. Preserve previous comments.
6. Allow authorized users to view task discussions.
7. Record relevant progress updates in the activity history.

## Expected Result

Employees and managers can communicate about task progress without relying entirely on separate messages.
