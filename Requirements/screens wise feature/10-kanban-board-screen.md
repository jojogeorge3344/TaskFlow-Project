# SCREEN 10: Kanban Board Screen

> Source: BRD for Task management.docx · TaskFlow – Intelligent Task Allocation & Tracking System · v1.0 · §2.10

**Screen Name:** Task Board
**Access:** All users, subject to task permissions

## Purpose

Provide a visual representation of task progress.

## Screen Elements

Four columns:

1. To Do.
2. In Progress.
3. Blocked.
4. Completed.

Each task card displays:

- Task ID.
- Task title.
- Assigned employee.
- Priority.
- Deadline.
- Current status.

## Functional Requirements

1. Display tasks in columns based on their current status.
2. Allow authorized users to change task status.
3. Update the database when a task's status changes.
4. Record status changes in the activity history.
5. Highlight overdue tasks.
6. Prevent unauthorized status changes.
7. Refresh the board to reflect the latest task status.

## Expected Result

Users can quickly understand the progress of multiple tasks.
