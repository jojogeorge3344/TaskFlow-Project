# SCREEN 18: Task Activity History Screen

> Source: BRD for Task management.docx · TaskFlow – Intelligent Task Allocation & Tracking System · v1.0 · §2.18

**Screen Name:** Activity History
**Access:** Authorized task participants and managers

## Purpose

Maintain a record of important changes to tasks.

## Screen Elements

- Task ID.
- Activity description.
- User who performed the action.
- Previous value.
- New value.
- Timestamp.
- Activity filters.

## Functional Requirements

1. Record task creation.
2. Record assignment and reassignment.
3. Record status changes.
4. Record deadline changes.
5. Record priority changes.
6. Record task completion.
7. Record relevant administrative actions.
8. Display activities in chronological order.
9. Prevent ordinary users from modifying or deleting historical activity records.

## Expected Result

Users can understand what changed, who made the change, and when it occurred.
