## 1. Module Overview
The Profile module ("My Profile") is where every signed-in user looks after their own account. Users can see their account details, update their name, email address and mobile number, and change their password. A password change is confirmed with a code from an authenticator app. The module only ever works on the signed-in user's own account. Nobody can open or change another person's profile here.

## 2. Purpose / Business Value
- Users can keep their own contact details up to date without asking an administrator (BRD Screen 19, "Expected Result").
- Users can change their password safely. The change needs a code from the authenticator app, and the user is then signed out on every device.
- Role, project, username, employee code and account status are shown but cannot be edited, so nobody can give themselves more access.
- Fewer routine requests reach administrators, and every user sees the same accurate account information.

## 3. Who Can Access This Module

| Role          | Can See Module | Can Use Module | Access Level (Own / Team / Organization) |
|---------------|:--------------:|:--------------:|------------------------------------------|
| Administrator | ✅ | ✅ | Own |
| Manager       | ✅ | ✅ | Own |
| Employee      | ✅ | ✅ | Own |
| Custom Role   | ✅ (Always On) | ✅ (Always On) | Own |

All four profile permissions are **Always On** for every role, including custom roles. They cannot be removed in Role Configuration. Even an Administrator can only see and change their own profile here. Other users' accounts are managed in **Employee Management**.

## 4. Screens in This Module

| # | Screen Name | Menu Path | Purpose | Visible To |
|---|-------------|-----------|---------|------------|
| 1 | My Profile | Side menu → **My Profile** (or the name/avatar link in the top bar) | View your account details and edit your personal information | All signed-in users |
| 2 | Change Password | My Profile → **Password** card → **Change password** | Set a new password, confirmed with an authenticator code | All signed-in users |
| 3 | Security Setup (Auth module) | Opened automatically after the first sign-in, before MFA is set up | Set up the authenticator app and get backup codes. The server side of this lives in the Profile module. | All signed-in users who have not set up two-step verification |

These keys are given to every user automatically. They are not stored per role and cannot be assigned or removed in Role Configuration.

## 7. Related Modules
- **Authentication** – After a password change the user signs in again. The Security Setup screen uses the Profile two-step verification actions. Account Recovery is the route for a forgotten password.
- **Management (Employee Management)** – Administrators manage the read-only fields shown on My Profile: role, projects, departments, username, employee code and status. Email uniqueness rules are shared.
- **Settings (Role Configuration)** – Lists the four profile permissions as Always On. They cannot be switched off.
- **TaskFlow Assistant (TFA)** – Can prepare a name or email change for the user to confirm, explains how to change a password, and links to My Profile.
- **Dashboard / shell** – The top-bar name updates as soon as the profile is saved. The **My Profile** menu item is always shown.

## 8. Expected Outcome
Every user, whatever their role, can open My Profile and see accurate details about their account. They can fix their own name, email and mobile number without asking an administrator. They can change their password safely: the change is confirmed with an authenticator code and signs them out everywhere. They cannot change their own role, projects or account status.
