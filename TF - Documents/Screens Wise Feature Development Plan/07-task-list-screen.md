# SCREEN 7: Task List Screen

> Source: BRD for Task management.docx · TaskFlow – Intelligent Task Allocation & Tracking System · v1.0 · §2.7

**Screen Name:** Task Management
**Access:** Administrator and Manager; employees see authorized tasks

## Purpose

Display and manage tasks in a structured list.

## Screen Elements

- Task ID.
- Task title.
- Assigned employee.
- Created by.
- Priority.
- Start date.
- Deadline.
- Estimated duration.
- Current status.
- Search field.
- Filters.
- Create task button.

## Functional Requirements

1. Display tasks according to the user's permissions.
2. Generate a unique task ID automatically.
3. Allow authorized managers to create and edit tasks.
4. Allow searching by task ID or title.
5. Filter tasks by employee, status, priority, and deadline.
6. Display overdue tasks with a clear visual indicator.
7. Display upcoming deadlines.
8. Allow users to open task details.
9. Prevent unauthorized users from modifying task assignments or deadlines.

## Expected Result

Users can find and manage relevant tasks without navigating through multiple screens.
