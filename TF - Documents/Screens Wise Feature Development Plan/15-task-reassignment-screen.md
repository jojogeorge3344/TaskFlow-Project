# SCREEN 15: Task Reassignment Screen

> Source: BRD for Task management.docx · TaskFlow – Intelligent Task Allocation & Tracking System · v1.0 · §2.15

**Screen Name:** Reassign Task
**Access:** Authorized Manager

## Purpose

Allow managers to transfer a task to another employee.

## Screen Elements

- Task ID.
- Task title.
- Current assignee.
- New assignee.
- Reassignment reason.
- Confirm reassignment button.
- Cancel button.

## Functional Requirements

1. Allow managers to select a new assignee.
2. Require confirmation before reassignment.
3. Record the previous and new assignee.
4. Record the reassignment timestamp and responsible user.
5. Preserve existing task comments and history.
6. Notify the new assignee about the task assignment.
7. Update the task's notification recipients according to the configured recipient rules.
8. Preserve access to historical records for authorized users.

## Expected Result

Tasks can be transferred without losing their previous history.
