# SCREEN 16: Employee Workload Screen

> Source: BRD for Task management.docx · TaskFlow – Intelligent Task Allocation & Tracking System · v1.0 · §2.16

**Screen Name:** Employee Workload
**Access:** Administrator and Manager

## Purpose

Help managers understand how work is distributed among employees.

## Screen Elements

- Employee name.
- Department.
- Active task count.
- High-priority task count.
- Overdue task count.
- Completed task count.
- Workload summary chart.
- Employee filter.

## Functional Requirements

1. Calculate active tasks for each employee.
2. Display overdue and high-priority task counts.
3. Allow filtering by department and employee.
4. Allow managers to open an employee's authorized task list.
5. Highlight employees with unusually high active task counts.
6. Use workload information to support task allocation decisions.

## Expected Result

Managers can identify workload imbalances and distribute tasks more effectively.
