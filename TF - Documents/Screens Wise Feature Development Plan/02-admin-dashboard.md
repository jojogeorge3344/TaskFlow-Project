# SCREEN 2: Admin Dashboard

> Source: BRD for Task management.docx · TaskFlow – Intelligent Task Allocation & Tracking System · v1.0 · §2.2

**Screen Name:** Administrator Dashboard
**Access:** Administrator

## Purpose

Provide an overview of employees and overall task management activity.

## Screen Elements

- Total employees card.
- Active employees card.
- Total tasks card.
- Pending tasks card.
- Completed tasks card.
- Overdue tasks card.
- Department summary.
- Recent system activity.
- Sidebar navigation.

## Functional Requirements

1. Display the total number of registered employees.
2. Display the number of active employees.
3. Display total, pending, completed, and overdue tasks.
4. Show task statistics by status.
5. Display recent employee and task activity where appropriate.
6. Provide navigation to employee management and department management.
7. Allow the administrator to open relevant records from dashboard cards.

## Expected Result

The administrator can understand the overall state of the application from one screen.
