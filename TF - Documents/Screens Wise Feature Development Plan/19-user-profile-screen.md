# SCREEN 19: User Profile Screen

> Source: BRD for Task management.docx · TaskFlow – Intelligent Task Allocation & Tracking System · v1.0 · §2.19

**Screen Name:** My Profile
**Access:** All registered users

## Purpose

Allow users to view their personal account details.

## Screen Elements

- Employee name.
- Email address.
- Department.
- Role.
- Account status.
- Change password form.
- Save changes button.

## Functional Requirements

1. Display the logged-in user's profile information.
2. Allow permitted profile fields to be updated.
3. Validate email addresses and other inputs.
4. Allow users to change their passwords securely.
5. Require the current password when appropriate.
6. Prevent employees from changing their own role or account status.

## Expected Result

Users can maintain their profile details without administrator assistance for routine updates.
