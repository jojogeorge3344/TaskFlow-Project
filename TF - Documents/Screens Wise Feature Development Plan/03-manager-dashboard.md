# SCREEN 3: Manager Dashboard

> Source: BRD for Task management.docx · TaskFlow – Intelligent Task Allocation & Tracking System · v1.0 · §2.3

**Screen Name:** Manager Dashboard
**Access:** Manager

## Purpose

Help managers monitor assigned work, upcoming deadlines, and employee workload.

## Screen Elements

- Total tasks.
- Tasks due today.
- Upcoming deadlines.
- Overdue tasks.
- Completed tasks.
- Tasks by status chart.
- Employee workload summary.
- Recent task activity.
- Quick task creation button.

## Functional Requirements

1. Display task statistics for the manager's authorized scope.
2. Show tasks approaching their deadlines.
3. Highlight overdue tasks.
4. Display the assigned employee and current status for each task.
5. Show the number of active tasks assigned to each employee.
6. Allow managers to open a task from the dashboard.
7. Provide a shortcut to create a new task.
8. Display recent task updates.
9. Allow filtering by employee, priority, and status where appropriate.

## Expected Result

Managers can quickly identify pending work, overloaded employees, and tasks requiring attention.
