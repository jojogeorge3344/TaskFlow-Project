# SCREEN 17: Reports Screen

> Source: BRD for Task management.docx · TaskFlow – Intelligent Task Allocation & Tracking System · v1.0 · §2.17

**Screen Name:** Task Reports
**Access:** Administrator and Manager

## Purpose

Provide reports about task allocation and completion.

## Screen Elements

- Date-range filter.
- Employee filter.
- Department filter.
- Status filter.
- Priority filter.
- Total task count.
- Completed task count.
- Pending task count.
- Overdue task count.
- Completion summary chart.
- Export CSV button.

## Functional Requirements

1. Generate task reports using selected filters.
2. Display task counts by status.
3. Show completed and overdue task statistics.
4. Filter reports by employee, department, priority, and date range.
5. Export authorized report data to CSV.
6. Ensure that reports contain only records the user is permitted to access.
7. Use consistent rules when calculating task status and overdue counts.

## Expected Result

Managers can review task performance and export reports for office use.
