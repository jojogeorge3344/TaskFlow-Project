# SCREEN 12: Notification Center Screen

> Source: BRD for Task management.docx · TaskFlow – Intelligent Task Allocation & Tracking System · v1.0 · §2.12

**Screen Name:** Notifications
**Access:** All registered users

## Purpose

Display task-related alerts and reminders.

## Screen Elements

- Notification bell in the navigation bar.
- Unread notification count.
- Notification list.
- Notification type.
- Message.
- Timestamp.
- Related task link.
- Mark as read button.
- Mark all as read button.
- Notification filters.

## Functional Requirements

1. Display notifications for the logged-in user.
2. Show the number of unread notifications.
3. Create notifications for task assignments.
4. Create reminders for approaching deadlines.
5. Create due-today alerts.
6. Create overdue alerts.
7. Allow users to mark notifications as read.
8. Allow users to open the related task.
9. Prevent users from viewing another user's private notifications.
10. Prevent duplicate reminder events.

## Expected Result

Users can view and manage their task-related notifications from one place.
