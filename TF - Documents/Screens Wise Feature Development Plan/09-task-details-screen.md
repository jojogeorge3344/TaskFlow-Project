# SCREEN 9: Task Details Screen

> Source: BRD for Task management.docx · TaskFlow – Intelligent Task Allocation & Tracking System · v1.0 · §2.9

**Screen Name:** Task Details
**Access:** Authorized users associated with the task

## Purpose

Display all information related to an individual task.

## Screen Elements

- Task ID.
- Task title.
- Description.
- Assigned employee.
- Task creator.
- Priority.
- Start date.
- Deadline.
- Estimated duration.
- Current status.
- Task comments.
- Notification recipients.
- Activity history.
- Edit task button.
- Update status control.

## Functional Requirements

1. Display all task details.
2. Allow authorized users to update task status.
3. Allow authorized managers to edit task information.
4. Allow authorized managers to reassign tasks.
5. Display the task's notification recipients.
6. Display task comments and progress updates.
7. Display the history of important task changes.
8. Show whether the task is upcoming, due today, overdue, or completed.
9. Stop deadline reminders when the task is completed or cancelled.
10. Record important changes in the task activity history.

## Expected Result

Authorized users can view a task's complete information and current progress.
