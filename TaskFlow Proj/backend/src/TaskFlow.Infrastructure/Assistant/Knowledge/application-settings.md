Administrators open **Settings > Application Settings**.

- Set the application name, timezone and the default task priority.
- Turn in-app notifications on or off.
- **AI assistant:** enable Ollama, Google Gemini or OpenAI GPT for TFA, set the model name, enter the API key (Gemini and OpenAI) and use **Test connection**. Keys are stored encrypted and are never shown again after saving. OpenAI has no free tier: it needs a paid key.
