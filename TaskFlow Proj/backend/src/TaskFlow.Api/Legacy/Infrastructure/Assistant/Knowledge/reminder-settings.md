Managers and Administrators open **Settings > Reminder Settings**.

- Turn reminders on or off, and the deadline-day reminder.
- Set the default days before a deadline for the first and second reminder.
- Choose how often overdue reminders repeat.
- Choose whether reminders are also delivered to Mail.

Each task can override the reminder days when it is created or edited.
