Only Administrators change roles.

1. Open **Employee Management** (under TaskFlow Management).
2. Edit the user and choose the new role: Administrator, Manager or Employee.
3. Save. The user is signed out and signs in again with the new role.

I can prepare a role change for you too: tell me who and which role, review it and confirm.
